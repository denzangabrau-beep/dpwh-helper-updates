# DPWH Helper – downloads

Latest version: **v0.2.16** (2026-11-05) – smooth S-curve in the PDM

- **Android tablet / phone:** [DPWH-Helper.apk](https://github.com/denzangabrau-beep/dpwh-helper-updates/raw/main/DPWH-Helper.apk) – open it and tap Install / Update.
- **Windows PC:** [DPWH-Helper-setup.exe](https://github.com/denzangabrau-beep/dpwh-helper-updates/raw/main/DPWH-Helper-setup.exe) – run it (SmartScreen: More info → Run anyway).

Once installed, the app updates itself: Settings → Updates, or **Update now** on the bar at the top.
Updating installs over the old app and keeps all data. Only the installers are here – no code and no data.
